# Hamza AboElEzz — Cybersecurity Portfolio

A polished, responsive, static portfolio for Hamza Moataz Elsayed Mohamed AboElEzz.

## Features
- Dark cyber-inspired visual design
- Responsive layout for desktop and mobile
- Five project showcases with interactive detail dialogs
- Category filtering (AppSec, Blue Team, Assessment)
- Downloadable Word CV
- Accessible navigation, reduced-motion support, and semantic HTML
- No framework, API key, or build step required

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a new public repository, for example `hamza-cyber-portfolio`.
2. Upload **all files and the `assets/` folder** from this directory to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)`, and save.
5. Once deployment completes, GitHub Pages will show the public site URL.

## Customize
- `index.html`: text, projects, contact information, GitHub link
- `styles.css`: theme and layout
- `script.js`: project descriptions, filters, and dialogs
- `assets/`: CV and other downloadable files

**Note:** Project links currently lead to the GitHub profile, not to unverified repository URLs. Replace them with verified repository links when available. Descriptions should be reviewed against the implemented code before public claims of functionality.

## Privacy
The email address is publicly visible on the site. The site does not include analytics or a contact form. Fonts are loaded from Google Fonts; replace the font import with system fonts if you prefer to avoid third-party font requests.
